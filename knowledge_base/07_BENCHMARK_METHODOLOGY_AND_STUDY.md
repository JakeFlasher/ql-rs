# Benchmark Methodology and Empirical Study

## 1. Why a dedicated harness

A fair quantitative benchmark must measure complete domain work, not a micro-kernel detached from calibration, allocation, or numerical validation. C++ QuantLib-style comparisons often rely on separate processes, hand-tuned warmups, and opaque compiler flags; cross-process timing loses cache state and makes parity difficult to audit. ql-rs instead keeps both closures in one deterministic Rust process, uses identical inputs and RNG seeds, and asserts a numerical checksum before a speedup is reported.

The harness in `crates/ql-benches/src/harness.rs` performs warmups, repeated fixed-size iterations, sorting, median/IQR calculation, and `black_box` barriers. `run_comparison` records the final values and fails if the absolute parity difference exceeds the suite tolerance. `scale` changes only repetitions, so `ns/op` retains the same workload definition in tests and release runs.

Current release scope: **39 benchmark suites** and **37 workstation tabs**.

## 2. Mathematical interpretation

- **Adjoint complexity:** Giles–Glasserman reverse AAD propagates a scalar payoff adjoint through a path graph once. After primal work, the reverse sweep is approximately independent of the number of input risk factors, unlike one bump-and-revalue per quote.
- **IFT calibration:** If calibrated parameters solve $F(\theta,q)=0$, the exact quote Jacobian is $d\theta/dq=-J_\theta^{-1}J_q$. ql-curves, ql-credit, ql-inflation, ql-rates, and ql-commodities cache this linear algebra; suites 03 and 09 compare it against full rebootstrap bumps.
- **Tape checkpointing:** Savine-style marks and rewinds reuse the path-local tape arena. The pathwise MC benchmark measures both Greek parity and bounded tape length rather than merely checking finiteness.
- **Fuzzy AAD:** Discontinuous scripted triggers use smooth truth weights so pathwise Delta/Vega remain meaningful. Suite 07 compares one fuzzy-AAD pass with independent central bumps.
- **Data-oriented kernels:** SoA legs, SIMD lanes, contiguous PDE lines, and in-place ASB recursion isolate the gains from locality and vectorization without changing formulas.

## 3. Statistical protocol

Each suite has a deterministic workload, one warmup, 3 timing samples, and a configurable repetition count. Samples report median and IQR nanoseconds per operation. Parity tolerances are domain-specific: exact integer counts use zero tolerance; prices and Greeks use absolute tolerances tied to finite-difference noise. The release report is generated by `cargo run -p ql-benches --release` and written to both `crates/ql-benches/BENCHMARK_RESULTS.md` and `knowledge_base/08_BENCHMARK_RESULTS.md`.
